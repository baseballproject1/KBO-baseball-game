## 🎴 주요 시스템

### 선수 시스템
- KBO 선수 데이터
- 팀별 선수 관리
- 등급별 카드


### 뽑기 시스템
- 일반 뽑기
- 고급 뽑기
- 레전드 뽑기 불가

- 강화 성공 확률

제작 비용:

150억
